# ONE PIECE相場

通常ブースターの直近5弾（2026-09-04時点）、OP-13〜OP-17を対象とする。
各弾10種の高額カード・スペシャルカードと未開封BOX1種を選抜。
カタログの `official_url` は発売情報、`selection_url` は選定参考資料、
各商品の `source_url` は実際の価格取得元。

## 価格

- スニダンの商品IDを固定し、同番号の通常版・別パラレル・再録を区別する。
- カードは状態Aのみ。PSA・状態B〜Dは混ぜない。
- BOXは `size` の箱数で合計価格を割り、1箱単価にする。不明な単位は除外。
- 各記録日までの30日間から新しい日順に20件を目安に収集し、日単位で打ち切る。
  最低3件で平均を計算。同日の一部だけを選ばない。
- 記録日は成約があった日。取得日のダミー価格は追加しない。
- 30日以上前の最終相場は参考値と表示。必要件数がなければデータ不足。
- 価格帯は採用した約定の20〜80パーセンタイル。
- 相対日付はJSTで推定されるため、直近の成約件数は暫定。
- 取得上限で途中までの履歴しか得られない場合、最古日の途中集計を捨てる。
  新しい側の必要件数が揃った窓だけ採用し、過去の記録は維持する。
- `sales_by_day` は取得範囲内の取引件数。箱数や全期間の出来高ではない。

## 更新

```sh
npx tsx scripts/verify-onepiece.ts
npx tsx scripts/scrape-onepiece-prices.ts
# 特定の弾・商品だけ
npx tsx scripts/scrape-onepiece-prices.ts op17
```

`.github/workflows/update-onepiece-prices.yml` はJST 9:30 / 21:30に更新。
取得失敗した商品の価格ファイルは維持し、成功分のみ保存する。
一部でも失敗した実行はActionsで失敗として報告する。
ポケカのデータ・予想生成はこの更新処理に含めない。

カタログの取り込みは `node scripts/import-onepiece-catalog.mjs`。
既に登録済みの弾は維持するため、対象変更時はカタログを明示的に見直す。
