# サイト来訪者カウンター（2026-11-17）

共通ヘッダーの下に「今日の来訪者」「累計来訪者」を表示。ポケカ・ワンピース共通のサイト全体の集計。

- 日本時間の日別に、同一IPの再訪を重複集計しない概数。共有回線の複数人などは区別できない。
- 累計は集計開始日からの日別人数の延べ合計。過去のカード閲覧数からの推計・水増しは行わない。
- IPそのものを保存せず日付とIPのハッシュで重複判定。重複防止値は当日・前日分のみ保持し、新規来訪記録時に古い値を削除。集計済み人数は保持。
- テーブルはRLS有効・公開読み書き禁止。公開用RPCは集計値だけを返し、匿名サインイン不要。
- 読み込み中・取得障害は「—」と状態表示。0人と欠測を区別。60秒ごと／再表示時に更新し、日付切替にも追従。
