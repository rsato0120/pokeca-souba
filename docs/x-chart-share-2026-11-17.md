# X共有へのグラフ画像追加（2026-11-17）

カード・BOX・ワンピースの商品詳細の「Xでシェア」から、表示中の価格グラフをPNG画像にするプレビューを開く。

- 予測／履歴、素体／PSA10、期間、テーマ、BOX系列を現在の表示から取得。
- 商品名・観測日・凡例を追加。BOXの混在系列による代替グラフは画像と投稿文に明記。
- Web Shareのファイル共有対応端末では画像と投稿文を共有メニューへ渡す。共有先でXを選ぶ。アプリ対応状況は端末依存。
- 全端末でPNG保存と文章入りX投稿画面へのリンクを提供。Web Intent自体には画像を自動添付しないため、非対応ブラウザーでは画像を保存して手動添付する。
- 画像生成不能・データ不足時も文章のみの投稿リンクを利用可能。自動投稿・Xログイン・新しい権限は不要。

検証：本番ビルド1607ページ、型検証、変更コンポーネントのESLint。PlaywrightでPNGの生成・保存、予測・PSA10/90日、PSA10のみのカード、BOX、ワンピース、ライト／ダーク、1440px／390px、モーダルの閉じる操作を確認。共有APIはモックでファイル名・MIME・画像・投稿文・キャンセル処理を検証。OSの共有メニューから実際のXアプリへの受け渡しは実端末未検証。実際のX投稿は行っていない。

既存作業の変更は含めず、origin/mainの隔離worktreeで実装。
